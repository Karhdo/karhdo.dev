## Tech stack

This blog is built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/), rebuilt from its original **Tailwind Nextjs Starter Blog** base.

This blog site takes inspiration from leohuynh.dev. I appreciate [Leo Huynh](https://twitter.com/hta218_) and [Timothy Lin](https://twitter.com/timlrxx) for their contribution to this minimal, lightweight, and highly customizable blog starter.

A few major over-engineering-changes from the original repo:

- <Twemoji className="mr-2!" emoji="atom-symbol" /> Rebuilding on **Astro 7** with **React 19** islands, **Tailwind CSS v4**, **Bun** and **Drizzle**.
- <Twemoji className="mr-2!" emoji="party-popper" /> Adopting **Typescript**, committing with [Conventional Commits](https://www.conventionalcommits.org)
- <Twemoji className="mr-2!" emoji="bar-chart" /> Monitoring site with [Umami](https://umami.is/) website analytics
- <Twemoji className="mr-2!" emoji="eyes" /> Theming in dark mode with [Tokyonight Neovim Theme](https://github.com/folke/tokyonight.nvim) colors for better contrast.
- <Twemoji className="mr-2!" emoji="man-technologist" /> My website refers to the design and code from the [lehuynh.dev](https://github.com/hta218/leohuynh.dev) repository and was originally based on the tailwind-nextjs-starter-blog template, version 2.0, before being rebuilt with Astro.
- <Twemoji className="mr-2!" emoji="inbox-tray" /> Bumping up `rehype`/`remark` plugins and dependencies to the latest version

See my [repository](https://github.com/Karhdo/karhdo.dev) for this blog.
