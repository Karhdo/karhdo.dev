# 01 — Scaffold Astro on Bun and remove the Next.js stack

## Endpoint

None.

## Summary

Turn the `v2` branch into a minimal, buildable Astro 7 project managed by Bun, with the Vercel (Node) adapter, React and MDX integrations and Tailwind v4 wired in. Delete every Next.js, Contentlayer, Prisma client, ESLint, Prettier, Husky/lint-staged and Next Docker artefact. Keep content (`data/`), static assets (`public/`) and the Prisma schema/migrations (reference for task 05) until their owning tasks move or delete them. All later tasks read v1 sources via `git show main:<path>` (branch `main` == v1; `origin/v1` also preserves it).

## Implementation Steps

1. Confirm the branch is `v2` and the tree is clean; record `git rev-parse main` in the PR description as the v1 reference.
2. `mkdir -p src/assets/icons && git mv icons/miv.svg src/assets/icons/miv.svg` (must happen before `icons/` is deleted).
3. `git rm -r` the paths in **Delete** (tracked ones) and `rm -rf` the untracked ones plus `node_modules`.
4. Write the new `package.json` (exact versions above; re-run `npm view <pkg> version` if more than a week has passed and bump).
5. `bun install` to create `bun.lock`.
6. Create `astro.config.mjs`, `tsconfig.json`, `src/styles/global.css`, `src/pages/index.astro`.
7. Update `.gitignore`, `.mcp.json`, `docker-compose.yml`.
8. Run `bun run build` (expect `.vercel/output/` with `static/` and `config.json`), `bunx astro check`, `bun dev` → open `http://localhost:4321/`.
9. `grep -rE "next|contentlayer|prisma|pliny" package.json astro.config.mjs tsconfig.json` returns nothing.

## Acceptance Criteria

- [ ] `bun run build` succeeds and produces `.vercel/output/config.json` and `.vercel/output/static/index.html`.
- [ ] `bunx astro check` passes with 0 errors (in particular no TS5101 `baseUrl` deprecation error).
- [ ] Biome is not installed yet; the `bunx biome check` gate starts in task 02.
- [ ] `src/assets/icons/miv.svg` exists (moved, not deleted).
- [ ] `bun dev` serves `/` with the placeholder page and Tailwind classes applied.
- [ ] No `next`, `contentlayer2`, `pliny`, `@prisma/*`, `prisma`, `eslint*`, `prettier*`, `husky`, `lint-staged`, `swr`, `react-snowfall` in `package.json` (`react-snowfall` is replaced by the dependency-free `Snowfall.astro` in task 29).
- [ ] `pnpm-lock.yaml`, `next.config.mjs`, `contentlayer.config.ts`, `app/`, `components/` no longer exist; `data/`, `public/static/`, `prisma/migrations/` still exist.
- [ ] `git log` on `v2` still contains v1 history (no force-push or rewrite).
